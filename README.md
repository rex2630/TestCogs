## Cogs

### [FlightWatch](flightwatch/README.md)

Search Ryanair fares without saving a watch, explore cheap destinations, and track one-way or return lows. Return watches can use simple outbound/return months or exact date windows. FlightWatch supports Czech and English responses, slash and prefix commands, IATA-code lookup, and optional price limits.

See the [English documentation](flightwatch/README.md) or the [Czech documentation](flightwatch/README.cs.md).

## Cogy

### [FlightWatch](flightwatch/README.cs.md)

Vyhledej lety bez uložení sledování, prozkoumej levné destinace a sleduj jednosměrná i zpáteční minima. Zpáteční sledování lze zadat jednoduše po měsících nebo přesnými daty. FlightWatch podporuje češtinu a angličtinu, slash i prefix příkazy, IATA kódy a volitelný cenový limit.

Podívej se na [českou dokumentaci](flightwatch/README.cs.md) nebo [anglickou dokumentaci](flightwatch/README.md).
